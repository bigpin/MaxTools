## 3 步上手：从安装到使用

### 第 1 步：获取这条快捷方式

打开微信小程序 **「Max 的工具宝藏」**，找到工具模块 **「iOS 快捷方式」**。

在页面顶部搜索栏输入 **「小红书」** 或 **「去水印」**，你会看到一条名为 **「小红书去水印」** 的卡片。

点击它 → 此时 iCloud 链接会自动复制到你的剪贴板。

接着在 iPhone 自带浏览器 Safari 中粘贴并打开这个链接，点击底部的「添加快捷指令」即可。

### 第 2 步：复制小红书链接

打开小红书 App，找到你想保存的笔记。

点击右上角的「分享」箭头图标 → 选择「复制链接」。

### 第 3 步：运行快捷方式

打开「快捷指令」App（或者直接从桌面/控制中心点击），运行刚才添加的「小红书去水印」。

它会自动读取你剪贴板里的链接，开始解析下载。

- 如果是图片笔记，它会保存所有图片。
- 如果是视频笔记，它会保存无水印视频。

**稍等片刻，打开相册，你想要的内容已经静静地躺在那里了，清清爽爽，没有水印。**
