## 开头

点外卖、打车、淘宝京东下单前，你一般会怎么做？

很多人是：打开 App → 选店选商品 → 直接下单。

结果同一单，别人用券实付 18 块，你原价 25。

不是你不会用券，而是——

- 美团的券藏在「我的」-「红包卡券」里，不点进去想不起来

**领券 30 秒，省下 3–20 块；不领，钱就白白多花。**

日积月累，一年下来少领几百块太正常了。

**今天介绍一个办法：一条 iOS 快捷方式，每天提醒你领券，美团 / 饿了么 / 淘宝 / 京东 / 滴滴的红包一站到位。**

## 这条快捷方式叫什么？能干什么？

名字：**「外卖红包·领券」**

它帮你做两件事：**领**和**提醒**。

| 功能 | 说明 |
|------|------|
| **外卖红包** | 每天领取 3–20 元档外卖红包，覆盖 **美团、饿了么、淘宝闪购、京东** |
| **滴滴打车券** | 每日滴滴打车券一并领取，出门前顺手领好 |
| **领券提醒** | 到点提醒你去领，不再「想起来已经过期」 |

一句话总结：

> **每天花几秒钟点一下，外卖、打车、网购的红包和券都能领到，还有提醒，不怕忘。**

而且：

- 运行在 iPhone 自带的「快捷指令」App 里，不用装额外软件
- 不涉及账号密码，只帮你跳转或复制领券链接
- 可以配合「自动化」设置每天固定时间提醒，养成习惯

## 3 步上手：从安装到使用

### 第 1 步：获取这条快捷方式

打开微信小程序 **「Max 的工具宝藏」**，找到工具模块 **「iOS 快捷方式」**。

在搜索栏输入 **「外卖」**、**「红包」**、**「领券」** 或 **「美团」**、**「饿了么」**，你会看到一条叫 **「外卖红包·领券」** 的卡片。

点击它 → iCloud 链接会自动复制到剪贴板。

然后在 iPhone 上打开 Safari，粘贴链接并访问，按提示点击「添加快捷指令」即可。

### 第 2 步：运行快捷方式

打开 iPhone 上的「快捷指令」App，找到刚添加的 **「外卖红包·领券」**，点击运行。

根据提示选择要领取的平台（美团、饿了么、淘宝、京东、滴滴等），或按顺序一键领完。

### 第 3 步：养成「下单前先领券」的习惯

领完券再去点外卖、打车、网购，付款时勾选对应红包即可抵扣。

**建议**：把这条快捷方式加到主屏幕或「快捷指令」小组件，每天早饭或午休前点一下，领完再点单，一个月下来能省不少。
