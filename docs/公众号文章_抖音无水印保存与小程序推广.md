## 这条快捷方式叫什么？能干什么？

名字：**「抖音多格式无水印保存」**

它不只是去水印，它能做到：

| 功能 | 说明 |
|------|------|
| 无水印视频 | 保存干净的原始视频到相册 |

| m4a 音乐 | 高音质音频格式 |
| 视频封面 | 把视频第一帧保存为图片 |
| 作者头像 | 保存博主头像图 |
| 音乐封面 | 保存 BGM 的专辑封面图 |

一句话总结：

而且：

- 运行在 iPhone 自带的「快捷指令」App 里，不用装额外软件
- 没有广告、没有弹窗、没有套路
- 可以放到控制中心，随时下拉一点就能用

## 3 步上手：从安装到使用

### 第 1 步：获取这条快捷方式

打开微信小程序 **「Max 的工具宝藏」**，找到工具模块 **「iOS 快捷方式」**。

在页面里搜索"抖音"或"去水印"，你会看到一条叫 **「抖音多格式无水印保存」** 的卡片。

点击它 → 链接会自动复制到剪贴板。

然后在 iPhone 上用 Safari 打开这个链接，按提示点击"添加快捷指令"就行。

> 你也可以把它加到控制中心里，这样以后从任意 App 下拉就能触发。

### 第 2 步：复制抖音链接

打开抖音，找到你想保存的视频。

点右边的「分享」按钮 → 选「复制链接」。

### 第 3 步：运行快捷方式

打开「快捷指令」App（或从控制中心点击），运行刚才添加的「抖音多格式无水印保存」。

它会自动识别你复制的链接，然后弹出选项：

- 要视频？→ 无水印视频直接存相册
- 要音乐？→ mp3 / m4a 任你选
- 要封面图 / 头像？→ 也能一键保存

**整个过程大约 10 秒，比你打开一个解析网站还快。**
